23 kasus cerita ala data operasional pabrik. Baca ceritanya, ketik query SQL kamu sendiri di kotak jawaban, baru klik "Cek Jawaban" buat cocokin sama kunci jawaban + penjelasannya. Mencakup JOIN, GROUP BY, HAVING, MAX/MIN per grup, COALESCE, NULL, RIGHT/FULL JOIN, CASE WHEN, subquery IN/EXISTS, UNION, dan window function — sesuai urutan di file Materi.
